# Bakery page

Bakery page is a website made with JavaScript, HTML, CSS and Bootstrap, using Webpack as a module bundler. Each page was created as a module in its own file, exporting a function that creates a div element, adds the page content and styles, and then appends it to the DOM. Navigation through the page is possible through the nav buttons, that renders each page accordingly.

This project was made for The Odin Project's JavaScript course.
